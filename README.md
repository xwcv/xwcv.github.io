# xwcv theme

Source of [Xinggang Wang's academic homepage](https://xwcv.github.io/)
(华中科技大学 王兴刚教授主页). Static HTML, no build step; `res/site.js`
progressively enhances the pages in the browser. The site's code and design
are reusable as the **xwcv theme** — see the license terms below.
